# gunkata knowledge base

This bundle holds what must still be true in a fresh clone, to a reader who was not in the
session that learned it: the reasoning behind the engine's locks, findings about the tools
and platforms gunkata depends on, and references to outside material the project relies on.
One concept per file, full frontmatter, sources on every claim.

It refuses three things. **State** - run counts, in-flight work, versions of things that
change with the next commit - belongs to its authoritative source, not here; a number lives
in a concept only when the number is the finding. **Secrets** of any kind, because git
history is permanent. **Standing orders**, which belong in `/AGENTS.md`: when a decision
produces both a law and a rationale, `AGENTS.md` gets the one-line law and the rationale
lives here.

Conventions: `decisions/` holds `Decision`, `findings/` holds `Finding`, `references/` holds
`Reference`, and the generator rejects anything else. Deprecate, never delete. The listing
below is generated by `scripts/kb_index.py` - edit concepts and regenerate; pre-commit
enforces `--check`. There is no update log; git history is the log.

# Decisions

* [A run ends when its process tree is dead](decisions/a-run-ends-when-its-process-tree-is-dead.md) - Teardown is part of the run contract; the engine owns the full process tree via process groups.
* [Completion is verified, never claimed](decisions/completion-is-verified-never-claimed.md) - A task is done when its named evidence artifact exists and passes its check; dependents release only after verification.
* [Cost is observability, never control flow](decisions/cost-is-observability-never-control-flow.md) - Dollar amounts are recorded and reported but no bound in the engine may read one.
* [Evidence is files and exit codes](decisions/evidence-is-files-and-exit-codes.md) - The engine gates on artifacts on disk and transcripts synced into its own dedicated pond, never on a stream, a status field, or an agent's say-so.
* [Model-free grading from day 0, one case first](decisions/model-free-grading-from-day-0-one-case-first.md) - The corpus starts with exactly one deterministic case the engine must pass before anything else is built, and grader tests never involve a model.
* [No retry without classification](decisions/no-retry-without-classification.md) - A failure is classified from transcript evidence before any retry; unclassified failures park the task.
* [The quality gate is nix, just and lefthook](decisions/the-quality-gate-is-nix-just-and-lefthook.md) - Three tools own three non-overlapping jobs - provisioning, task running and index-aware hooks - because each candidate for collapsing them fails on a specific, verified capability gap.
* [Zero process-global state](decisions/zero-process-global-state.md) - Every run gets its own ports, temp dirs and config paths; no defaults are shared between runs.

# Findings

* [A gate must run inside the pinned dev shell](findings/a-gate-must-run-inside-the-pinned-dev-shell.md) - A hook inherits the invoking shell, so an environment cached before a flake change fails the gate with a bare exit 127; the pre-push hook therefore wraps itself in nix develop.
* [A bare executor HOME must still carry the agy server directory](findings/executor-homes-need-the-agy-server-dir.md) - The Antigravity ACP wrapper resolves its .par through $HOME, so an engine-owned HOME breaks executor startup until the server directory is explicitly inherited alongside the credentials.
* [lefthook guarantees less about the index than it appears](findings/lefthook-guarantees-less-about-the-index-than-it-appears.md) - stage_fixed re-stages the list it was given rather than what changed, only partially staged files are hidden, the backup stash is shared across linked worktrees, and LEFTHOOK=0 turns any run into a silent pass.
* [acpx is not flake-pinned; executor CLIs never will be](findings/runtime-deps-not-yet-flake-pinned.md) - pond is packaged in the flake from its release binaries, acpx is host-provided pending a pnpm packaging route, and the executor CLIs are host-provided by necessity.
